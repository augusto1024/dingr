BRING THE SOUND TO YOUR APP

Sound effects, made with code.

dingr is a JavaScript and TypeScript audio library for UI sounds, notifications, and game effects. Synthesize tones, compose musical sequences, and export mono WAV files in Node.js or the browser.

No recorded samples or runtime dependencies. Save editable JSON recipes to reproduce your sounds. Free for personal and commercial use under the Unlicense, with no attribution required.

A SOUND IN THREE LINES

import { createSound, render, encodeWav } from "dingr";

const recipe = createSound("kalimba", { note: "C4" });
const sound = render(recipe);
const wav = encodeWav(sound);
